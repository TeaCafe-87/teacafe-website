## ☕ About TeaCafe

**TeaCafe** 是一個 Minecraft 伺服器與玩家社群。

我們希望建立一個舒適、完整且具有自己特色的遊戲環境，
讓玩家不只是進入伺服器遊玩，也能透過網站取得 TeaCafe 的各種資訊與服務。

`teacafe-website` 將作為 TeaCafe 的官方 Web 平台。

---

## 🌐 Website

TeaCafe Website 預計提供：

- 🏠 **首頁**
  - TeaCafe 介紹
  - 重要資訊
  - 伺服器入口

- 📰 **最新消息**
  - 更新公告
  - 活動資訊
  - 維護通知

- 🟢 **Server Status**
  - 伺服器在線狀態
  - 玩家人數
  - 即時伺服器資訊

- 📖 **Wiki & Guides**
  - 遊戲指南
  - 系統介紹
  - 玩家教學

- 👤 **Player Services**
  - 玩家資料
  - 帳號系統
  - Minecraft 帳號整合

- 🛒 **TeaCafe Store**
  - 玩家商品
  - 特殊內容
  - 伺服器相關服務

- 🛠️ **Admin Services**
  - 網站管理
  - 玩家管理
  - TeaCafe 內部服務
